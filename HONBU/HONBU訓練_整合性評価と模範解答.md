# HONBU本部訓練 整合性評価と模範解答

## 1 評価の結論

この訓練は、地震発生、本部設置、多数傷病者受入、患者転送、余震、商用停電、自家発電運転、エレベーター停止という流れで構成されており、複合災害下の本部活動を扱う骨格は妥当である。

一方、本部訓練としての完成度は「要修正」である。最大の問題は、本部が確認すべき情報と判断基準が十分に与えられないまま、「全応需」「ICU患者を一般床へ移して空床化」「DMAT派遣検討」などの結論がシナリオ上で先に定められている点である。この構成では、TKHBCPが求める現状分析、病院行動評価群の判定、優先業務に基づく資源配分、診療制限、受援及び再評価を訓練しにくい。

実施済みの「現状分析と課題」2部は、施設・ライフラインの一部に記入があるものの、患者、人員、診療機能、物資、外部状況、支援要請、評価群、大方針、活動方針がほぼ空欄である。空欄が「未確認」を意味するのか「問題なし」を意味するのかも区別されていない。このため、本部としての意思決定と指揮統制は記録上確認できない。

本評価は、TKHBCPのオールハザード型BCP改訂原案を基準とする。同原案には暫定値及び要確認事項が含まれているため、人数、設備能力、燃料時間、連絡先などの当院固有情報は、所管部署の確認後に確定する必要がある。

## 3 本部要員として問題となる点

実施記録の空欄は、実際に実施しなかった場合と、実施したが記録しなかった場合を区別できない。本部訓練では、記録されない意思決定は検証不能であるため、いずれも改善対象とする。

1. **役割分担が記録されていない。** 本部長、副本部長の担当領域、実務統括、事務局、記録、EMIS、外部連絡の担当が不明である。
2. **情報の確度を区別していない。** 確認済み、未確認、推定、復旧見込みが分けられていない。空欄を「異常なし」と解釈してはならない。
3. **Sceneに偏り、SurvivorとSelfが欠落している。** 患者数、重症患者、人工呼吸器・透析・手術中患者、職員数、物資、自律可能時間が把握されていない。
4. **病院行動評価群を判定していない。** 評価群0からIIIのどこに該当するか、その根拠がない。
5. **大方針を宣言していない。** 全避難、籠城、診療制限下の継続、通常・拡張運用のどれを選ぶかが不明である。
6. **診療機能別の判断がない。** 救急、外来、予定手術、緊急手術、透析、検査・画像、入院、薬剤を一括で扱っている。
7. **受入能力を数値化していない。** 赤・黄・緑別の受入数、ICU/HCU、手術室、一般病床、輸血、検査、搬送人員を確認せず全応需としている。
8. **指示に担当者と期限がない。** 「検討」「確認」だけで、誰がいつまでに何を報告するかが決まっていない。
9. **定時会議と再評価時刻がない。** 状況が変化しても、共通状況認識を更新する仕組みが弱い。
10. **クロノロジーが見えない。** 判断者、判断時刻、根拠、指示先、完了確認が記録されていない。
11. **EMIS及び外部発信が未実施又は未記録である。** 地震、自院被災、多数傷病者、停電は速やかな更新対象である。
12. **職員安全と持続性が扱われていない。** 安否、参集可否、交代、休憩、食事、帰宅困難、家族事情が評価されていない。
13. **受援の具体性がない。** 必要な支援の種類、数量、期限、受入場所、連絡窓口が定められていない。
14. **余震時の安全確保後、建物・患者・設備の再点検を全領域でやり直していない。** 余震は新しい災害としてScene、Survivor、Selfを再評価する必要がある。

## 4 模範解答 1回目 9時40分時点

### 4.1 現状分析

**確認済みの事実**

- 9時15分に地震発生。Dモードを発令した。
- 9時20分にF棟災害対策本部室へ本部を設置した。
- 倒壊、火災、浸水は現時点の緊急報告では確認されていない。
- 商用電源、医療ガス、空調、下水、院内通信は使用可能と報告されている。
- A西7病棟及びSCUで水が出ない。
- A東7病棟でPC2台が転倒し故障した。
- 小樽方面で多数傷病者事案が発生し、赤6名、黄10名程度が確認されている。搬送開始時刻は未確定である。
- ERは現場指令班の立上げと受入準備を要請している。

**未確認で、直ちに確認する事項**

- 建物安全の専門評価、危険区域、避難経路
- 地震による患者・職員・来院者の負傷者数
- ICU/HCU、手術室、一般病床、透析、検査、画像、薬剤、輸血の継続能力
- 赤・黄・緑別の安全な受入可能数と時間当たり処理能力
- 在院職員数、追加参集可能者、6時間後及び12時間後の交代要員
- 受水槽残量、断水範囲、復旧見込み、下水及びトイレの使用可否
- A東7の障害が端末2台のみか、ネットワーク又は電子カルテに波及しているか
- 周辺道路、他院の稼働状況、消防の搬送能力

### 4.2 暫定評価群と大方針

**暫定評価群はII**とする。場の安全及び生命維持機能は現時点で保たれているが、局所断水、端末故障、多数傷病者流入による病床・人員制約があり、制限下の診療継続が必要である。未確認事項が多いため、評価群IIIとはしない。

**大方針**は「患者・職員の安全を確保し、既存重症患者の生命維持を優先しながら、医療サージを起動する。予定診療を縮小し、確認できた能力の範囲で多数傷病者を段階的に受け入れる。10分ごとに再評価する」とする。

### 4.3 本部指示の模範例

| 期限 | 指示 | 主担当 | 完了報告 |
|---|---|---|---|
| 5分以内 | 全部署は余震に備え、患者・職員・来院者の負傷と危険区域を再確認 | 安全・警備・避難誘導 | 危険区域、負傷者数、避難要否 |
| 5分以内 | 本部機能の役割を割り当て、記録担当がクロノロジーを開始 | 本部長・事務局 | 担当者一覧、開始時刻 |
| 10分以内 | 赤・黄・緑別の受入可能数、ICU/HCU、手術室、一般病床を報告 | 診療継続・病床運用 | 数値と制約条件 |
| 10分以内 | A西7及びSCUは水使用を停止し、患者影響、代替水源、転棟候補を報告 | ライフライン・看護 | 残量、復旧見込み、必要支援 |
| 10分以内 | A東7のPC2台を安全に隔離し、代替端末又は紙運用の要否を確認 | 情報システム | 障害範囲、代替手段 |
| 10分以内 | 職種別の在院者、応援可能者、参集見込みを集計 | 職員管理 | 医師、看護師、技術職、事務、搬送別人数 |

| 15分以内 | EMISを更新し、消防へ条件付き受入可能数を回答 | 地域連携・受援 | 入力時刻、発信内容、支援要請 |
| 9時50分 | 第1回定時本部会議を開催 | 情報分析 | 評価群、大方針、未解決課題の更新 |

### 4.4 受入とDMAT派遣の模範回答

消防への回答は「全応需」ではなく、例えば「現時点の暫定受入は赤何名、黄何名、緑何名。重症病床・手術室の再編結果を9時50分に更新する。搬送前にホットラインで患者数と重症度を再連絡してほしい」とする。実数は、訓練注入資料に基づき決める。

DMAT派遣は、自院の本部、ER、ICU、手術、病棟、搬送の最低維持体制が確保され、今後の患者流入に対応でき、派遣先の明確なニーズと安全な活動条件が確認できた場合に限る。現時点では自院被災と赤6名・黄10名の流入が予測されるため、原則として院内対応を優先し、派遣は保留する。

## 5 模範解答 2回目 11時00分時点

### 5.1 現状分析

**確認済みの事実**

- 10時50分に震度6弱の余震が発生した。
- 商用電源が停止し、自家発電が稼働している。
- 余震後の緊急報告では複数部署に瞬時停電又は停電があり、停電範囲の表記はシナリオと報告書で一致していない。
- A西7病棟及びSCUの断水が継続している。
- A東7病棟のPC2台故障が継続している。
- ABF棟のエレベーター停止が手術室から報告され、患者退出経路の判断を求められている。
- 多数傷病者の受入は継続し、ICU・手術を要する患者が追加来院している。

**直ちに確認する事項**

- 余震後の建物安全、火災、漏水、医療ガス、危険区域、避難経路
- 自家発電の燃料残量、実負荷、残存運転時間、補給見込み、非常用回路及び過負荷
- 停電区域の正確な棟・部署、生命維持機器、空調、薬品冷蔵庫、ITへの影響
- 使用可能なエレベーター、非常用電源接続、復旧見込み、階段搬送の安全性
- 現在の重症患者数、ICU/HCU空床、手術室稼働、回復室、一般病床、転送候補
- 水、医療ガス、輸血、薬剤、食料の自律可能時間
- 職員の疲労、交代要員、搬送要員

### 5.2 暫定評価群と大方針

**暫定評価群はII**とする。自家発電により生命維持機能が保たれている限り、制限下で診療継続できる。ただし、燃料残存時間が24時間程度又は補給困難であれば、P-02の危機段階に近く、評価群Iへの移行を直ちに検討する。

**大方針**は「余震後の安全を再確認し、自家発電を生命維持、重症診療、本部、通信、情報システムへ優先配分する。予定診療を停止又は延期し、新規救急受入は病床・手術・電源能力の範囲に制限する。燃料補給と患者転送を並行して調整し、10分後に再評価する」とする。

| 11時10分 | 第2回定時本部会議を開催し、評価群Iへの移行要否を判断 | 情報分析 | 評価群、大方針、転送・避難の要否 |

### 5.4 エレベーター停止への模範回答

「ABF棟の停止中エレベーターは施設確認が終わるまで使用しない。手術終了患者は、現在地で安全な術後管理を継続する。施設担当は5分以内に使用可能な別号機と経路、非常電源、復旧見込みを報告する。代替エレベーターが使える場合は、重症度と搬送先病床を確認して順次搬送する。階段搬送は、生命に直結し待機できない患者に限り、医師、看護師、臨床工学技士、搬送要員、酸素、モニター、搬送器具を確保して実施する。安全な搬送が成立しない場合は、手術室又は回復室を一時重症管理区域として運用し、外部転送も検討する。」

## 7 訓練資料の修正案

1. 訓練目標を「本部設置」「30分以内の初回評価」「評価群と大方針」「診療機能別判断」「EMIS」「再評価」「記録」「受援」の8項目にする。
2. プレーヤー用資料とコントローラー用資料を分け、コントローラー用には各問い合わせへの回答、提示条件、想定時刻を記載する。
3. 詳細報告、病床数、手術室状況、ICU状況、職員数、燃料、自律時間、道路・他院情報を注入カードとして追加する。
4. 「全応需」「ICU空床化」などの結論を削除し、判断すべき問いと制約条件に置き換える。
5. 各インジェクトに、期待行動、許容される代替判断、重大エラー、評価点を設定する。
6. 現状分析票を改訂し、「確認済み・未確認」「評価群」「大方針」「課題」「影響」「担当」「期限」「必要資源」「再評価時刻」を必須欄にする。
7. 棟名称、様式版、ファイル番号、時刻を統一する。
8. 訓練終了前に最終本部会議を置き、未解決課題、24時間見通し、受援、交代勤務、次回評価を発表させる。

## 8 採点の目安

| 評価領域 | 合格の目安 |
|---|---|
| 指揮統制 | 本部設置後10分以内に役割、連絡経路、記録、会議時刻を明示 |
| 現状分析 | Scene、Survivor、Selfを確認済みと未確認に分けて整理 |
| 意思決定 | 評価群、大方針、診療機能別の継続・縮小・停止を根拠付きで決定 |
| 課題管理 | 各課題に担当、期限、必要資源、完了確認を設定 |
| 医療サージ | 受入能力を赤・黄・緑、重症病床、手術、人員で数値化 |
| ライフライン | 水・電源・燃料等を自律可能時間で評価し、節約フェーズを発令 |
| 外部連携 | EMIS、消防、行政、近隣医療機関への情報発信と支援要請を記録 |
| 再評価 | 余震等の変化後10分から15分以内に評価群と大方針を更新 |
| 持続性 | 交代勤務、休憩、食事、職員安全、24時間後の見通しを提示 |
| 記録 | 重要判断に時刻、判断者、根拠、伝達先、結果が残っている |
